Sliders — демонстрационный сайт

Статический HTML/CSS/JavaScript, без сборки и серверной части.
GitHub Pages публикует корень ветки main.

Полное меню временно отключено; карточки на главной сохранены.
Корзина демонстрационная, заказ не отправляется.
Макет — концепция сайта, не официальный сервис заказов.

Адаптивная версия: телефон, поворот экрана и планшет до 1000px.
На маленьких экранах карточки, контакты и корзина перестраиваются по ширине.
